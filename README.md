# New-ZuelGAL

框架：原生 JavaScript 驱动的 SPA-like (单页面) 架构 + PHP 路由分发器

构建工具：宝塔 (BT Panel) 自动化部署环境 + 原生 Web 标准

语言：PHP 8.1+、JavaScript (ES6+)、SQL (MySQL)

UI：原生 CSS3 (自定义暗黑视觉小说风格)、PDF.js (专业级 PDF 解析渲染引擎)

状态管理：PHP Native Session (服务端会话) & LocalStorage (客户端持久化缓存)

造型：原生 CSS (响应式 Flexbox 布局) + Glassmorphism (毛玻璃特效)

后端：PHP (LEMP 架构) + MySQL
